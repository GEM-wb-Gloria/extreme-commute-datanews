# 极端通勤地图：谁在大城市“跨城上班”
> **Interactive Data Journalism Project: The Extreme Commute Map**

## 📖 项目简介 (Introduction)

这是一个具有“滚动叙事（Scrollytelling）”体验的交互式数据新闻单文件作品。基于住建部与中国城市规划设计研究院（中规院）历年《中国主要城市通勤监测报告》实测大数据，聚焦全国超 1400 万承受单程 60 分钟以上“极端通勤”的都市跨城候鸟群体。

以宏大的交通地理流向网络、多维度空间错配图表、沉浸式时间成本计算器，直观透视当代中国大都市圈的“职住分离”与“空间折叠”。

## ✨ 核心特色 (Features)

1. **宏观空间错配透视**：可视化呈现京津冀、长三角、粤港澳大湾区核心产业高地与外围睡城的空间撕裂与房价梯度。
2. **权威级城际出行 OD 向量密集流向网络**：
   - 包含全国大盘、广东省全域 21 地市、京津冀廊雄、长三角沪苏昆常杭四大都市圈高密客流向量。
   - 严格采用等比色带编码交通运力梯级（`>80万` 鲜红巨带、`50~80万` 橙红特粗带、`10~50万` 暖橙粗带、`5~10万` 明黄中带、`1~5万` 翠绿细线、`≤1万` 浅绿微密线）。
   - 独立白底方框地名标牌，彻底杜绝线条文字挤压。
3. **时间成本与房价差额交互计算器**：动态滑动测算“用时间换空间”的真实经济账与年均消耗工时。
4. **单文件零依赖交付**：内嵌矢量行政区划边界与全部数据，基于 Tailwind CSS、ECharts 5 与 GSAP + ScrollTrigger 驱动。
